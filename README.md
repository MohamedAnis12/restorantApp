# craxe 🍔

A modern, high-performance food delivery mobile application built with **Flutter**. This app features a sleek user interface, category-based browsing, and a seamless shopping experience with full **Dark Mode** support.

---

## ✨ Features

* **User Authentication:** Clean Login and Signup interfaces.
* **Menu Discovery:** Browse food items by categories (Burgers, Pizza, Pasta, etc.).
* **Promotions:** Interactive banners for daily offers and discounts.
* **Item Details:** High-quality food previews with ratings, pricing, and descriptions.
* **Cart System:** Real-time quantity adjustments and total price calculation.
* **Dynamic Theming:** Seamless transition between **Light Mode** and **Dark Mode**.
* **Profile Management:** User account overview with "Add New Item" functionality.
